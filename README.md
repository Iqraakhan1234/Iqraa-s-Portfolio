
# Iqraa Khan — Multi-Page Developer Portfolio

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Open the terminal.
4. Run:

```bash
npm install
npm run dev
```

5. Open the localhost URL shown by Vite.

## Pages

- `/` Home
- `/about` About
- `/projects` Projects
- `/skills` Skills
- `/experience` Experience
- `/achievements` Achievements
- `/contact` Contact

## Before deploying

Replace:
- `yourmail@example.com`
- GitHub links
- LinkedIn link
- project demo links
- `/public/resume.pdf` with your actual resume

The project is intentionally built with React + Vite + React Router and does not require a backend.
